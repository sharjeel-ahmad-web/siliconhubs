# Blog Post Thumbnail Images

## Purpose
Featured images and thumbnails for blog posts shown on the homepage and blog listing page.

## Image Requirements
- **Dimensions:** 1200x630px (1.91:1 ratio - optimal for social sharing)
- **Format:** JPG or WebP
- **Max Size:** 400KB
- **Style:** Eye-catching, relevant to blog post content
- **Content:** Should represent the blog post topic

## Naming Convention
Use the blog post slug:
- `how-to-build-chatbots.jpg`
- `seo-best-practices-2026.jpg`
- `nextjs-performance-tips.jpg`

## How to Add Blog Thumbnails

### Method 1: Via Admin Dashboard (Recommended)
1. Go to `/admin/blogs`
2. Create or edit a blog post
3. In the "Featured Image" section, upload your image
4. The system will automatically handle storage

### Method 2: Manual Upload
1. Upload image to this folder
2. In the blog post editor, set the image path:
   ```
   /media/blog/thumbnails/your-image.jpg
   ```

## Image Content Guidelines

### ✅ Good Thumbnail Images:
- Clear, high-contrast
- Readable text overlay (if any)
- Relevant to topic
- Visually appealing
- Professional quality
- Mobile-friendly (important details visible when small)

### ❌ Avoid:
- Cluttered compositions
- Tiny text that won't be readable
- Overly dark images
- Irrelevant stock photos
- Low-resolution images
- Distracting backgrounds

## Social Media Optimization
These thumbnails are used for:
- Blog listing page
- Homepage blog section
- Open Graph (Facebook, LinkedIn)
- Twitter Cards
- Search engine results

### Recommended Specifications:
- **Facebook/LinkedIn:** 1200x630px (exactly this)
- **Twitter:** Works with 1200x630px
- **Pinterest:** Consider also creating 1000x1500px version

## Text Overlay Tips
If adding text to images:
- Use large, bold fonts (minimum 60px)
- High contrast (dark text on light bg or vice versa)
- Add shadow or outline for readability
- Keep text to 5-7 words maximum
- Test readability at thumbnail size
