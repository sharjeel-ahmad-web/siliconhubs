# Company Logos

## Purpose
Rising Dot Agency logos and brand assets in various formats and sizes.

## Logo Variants Needed

### 1. Primary Logo
- **Full color** (white background)
- **Full color** (transparent background)
- **White/Light** (for dark backgrounds)
- **Black/Dark** (for light backgrounds)

### 2. Logo Formats
- **Horizontal:** Full logo with text
- **Vertical:** Stacked version
- **Icon Only:** Just the symbol/mark
- **Text Only:** Just the wordmark

## File Requirements

### Vector Files (Preferred)
- **Format:** SVG
- **Naming:** 
  - `logo-primary.svg`
  - `logo-white.svg`
  - `logo-dark.svg`
  - `logo-icon.svg`

### Raster Files (Backup)
- **Format:** PNG with transparency
- **Sizes:**
  - Small: 200px width
  - Medium: 400px width
  - Large: 800px width
  - Extra Large: 1600px width

## Usage Guidelines

### ✅ Do:
- Use official logo files only
- Maintain proper spacing around logo
- Use correct color variants
- Keep aspect ratio
- Ensure readability at all sizes

### ❌ Don't:
- Stretch or distort logo
- Change colors
- Add effects (shadows, glows)
- Rotate logo
- Place on busy backgrounds
- Make logo too small (minimum 24px height)

## Clear Space
Maintain minimum clear space around logo:
- **Minimum:** Equal to height of "R" in Rising
- **Recommended:** 2x the height of "R"
- Keep free of text, graphics, other logos

## Minimum Sizes

### Digital
- **Website header:** 120px width minimum
- **Mobile header:** 80px width minimum
- **Footer:** 60px width minimum
- **Favicon:** 32x32px minimum

### Print
- **Business card:** 0.5 inches width minimum
- **Letterhead:** 1 inch width minimum
- **Large format:** Scale appropriately

## File Naming Convention

```
logo-[variant]-[color]-[size].[format]

Examples:
- logo-horizontal-color.svg
- logo-horizontal-white.svg
- logo-icon-dark.png
- logo-vertical-color-400px.png
```
